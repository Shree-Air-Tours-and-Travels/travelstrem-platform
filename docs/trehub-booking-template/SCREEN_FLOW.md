# Screen Flow

## Flights
Home → Flight Results → Flight Details → Fare Selection → Traveller Details → Add-ons → Review → Payment → Confirmation

Payment can branch to:
Payment → Failure → Retry Payment

Post-booking:
My Bookings → Booking Details → Change / Support / Cancellation Request

## Hotels
Home → Hotel Results → Hotel Details → Room Selection → Room Details → Guest Details → Review → Payment → Confirmation

Hotel details includes:
- Image gallery
- Overview
- Available rooms
- Amenities
- Location
- Guest reviews
- Property policies

Post-booking:
My Bookings → Booking Details → Change / Support / Cancellation Request
