# Trevista Tours & Holiday Packages Template

A responsive, production-style, zero-build UI prototype for the complete tours and holiday-packages booking lifecycle.

## Included customer flows

### Package discovery
- Destination-focused home page
- Holiday search form
- Destination cards
- Featured packages
- Complete package catalogue
- Budget, type, duration, and travel-style filters
- Sort options

### Package details
- Image gallery
- Overview and package highlights
- Day-wise expandable itinerary
- Hotel/stay information
- Inclusions and exclusions
- Booking, date-change, and cancellation policies
- Traveller ratings and reviews
- Package enquiry

### Booking flow
1. Departure selection
2. Traveller-count selection
3. Departure city and optional-flight choice
4. Room-category selection
5. Shared/private transport selection
6. Experience and insurance add-ons
7. Meal, bed, and special preferences
8. Traveller and passport forms
9. Final booking review
10. Payment
11. Payment failure and retry
12. Booking confirmation

### Custom trip
- Destination, dates, duration, and traveller inputs
- Trip style and interest selection
- Hotel and transport preferences
- Budget and flight inclusion
- Custom notes
- Quote-request confirmation

### Package enquiry
- Price and offer questions
- Package-customisation request
- Visa/passport/flight requirement help
- Callback preference
- WhatsApp placeholder

### Corporate and group tours
- Team offsites
- Incentive travel
- Conference travel
- Large-group proposal form

### Post-booking
- My Bookings dashboard
- Upcoming and enquiry states
- Booking details
- Pre-travel checklist
- Package and invoice downloads
- Change request
- Support request
- Cancellation and refund estimate

## Shared capabilities
- Responsive desktop, tablet, and mobile design
- Multi-step progress navigation
- Dynamic price recalculation
- Room, transfer, and add-on selection
- Traveller-count controls
- Modal workflows
- Toast notifications
- Secure-payment simulation
- Confirmation and failure states

## Run
Open `index.html` directly in a browser. No build process is required.

## Technology
- Vanilla HTML
- Vanilla CSS
- Vanilla JavaScript
- Lucide icons via CDN
- Inter font via Google Fonts
- Unsplash image URLs for demo imagery

## Production integration points
Replace mock data and simulated handlers with:
- Package catalogue API
- Availability and departure API
- Hotel and room inventory
- Transport and activity inventory
- Supplier price revalidation
- Traveller and document validation
- Coupon and promotion engine
- Payment gateway and webhooks
- Booking and itinerary generation
- Voucher and invoice generation
- Visa/insurance integration with TreCare
- Flight integration with TreHub
- CRM and holiday-expert assignment
- Support and cancellation workflows
