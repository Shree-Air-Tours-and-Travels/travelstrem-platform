# Trevista Screen Flow

## Curated package

Home → Package Results → Package Details → Departure → Customise → Travellers → Review → Payment → Confirmation

Payment can branch:
Payment → Failure → Retry

Post-booking:
My Bookings → Booking Details → Download Documents / Request Changes / Support / Cancellation

## Package enquiry

Package Details → Enquiry → Holiday Expert Assignment → Quote / Callback

## Custom trip

Custom Trip Form → Preference Submission → Expert Assignment → Itinerary Quote → Revision → Booking

## Corporate tours

Corporate Tours → Proposal Form → Requirements Review → Proposal → Group Booking
